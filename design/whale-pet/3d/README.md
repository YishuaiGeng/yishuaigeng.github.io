# Whale · 3D 初模与建模路线

这是保留现有鲸鱼标志的第一轮形体研究。模型有真实几何厚度、正反面、倒角与 PBR 材质，能旋转查看和改变光照。它由程序根据原有 SVG 轮廓构建；当前不是在 Blender 中完成的雕刻成品，也没有骨骼蒙皮。根据最新选择，主页已恢复二维鲸鱼并放在顶部导航栏的名字前；此三维模型保留为独立设计研究，主页默认不加载。

## 查看与文件

在仓库根目录启动本地静态服务器：

```bash
python -m http.server 8766 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8766/design/whale-pet/3d/`，可拖动旋转、切换正面/侧面/背面、调整厚度和粗糙度、比较两种腹部形态、播放摆尾和喷水，并导出当前设置的 GLB。

- `whale-outline-v01.glb`：中空轮廓，独立的悬浮眼球，偏向标志雕塑。
- `whale-volume-v01.glb`：增加浅色腹部及两侧眼睛，作为完整角色的探索起点。
- `contours.json`：来自 `src/data/whale-pet-artwork.json` 的轮廓快照。
- `preview-*.png`：不同视角与窄屏预览。
- `validation.json`：GLB 重新加载、尺寸、动画和交互检查结果。
- `../../../scripts/whale-pet/3d/model.mjs`：可调参数的建模源文件。
- `../../../scripts/whale-pet/3d/viewer.mjs`：预览、灯光和喷水。
- `../../../scripts/whale-pet/3d/fountain.mjs`：顶部原水花的形变、水滴轨迹及可导出的 `Fountain` 动画。

在服务器运行时重新生成与验证导出文件：

```bash
yarn node scripts/whale-pet/3d/export-models.mjs
```

## 后续怎样在 Blender 建模

建议使用 **Blender 制作最终模型和动作，Three.js 在主页显示，GLB 传递模型**。Figma 继续保存图形轮廓、色彩和表情参考。

1. **导入初模**：Blender → File → Import → glTF 2.0，选择上述 GLB。保存自己的 `.blend` 工作文件。模型包含命名分件、PBR 材质与 `Swim`、`Fountain` 动画。导入会自动转换 glTF 的坐标系。
2. **确定角色体积**：正面保持现有身体、眼睛、尾巴与水花的位置关系；同时绘制侧面和背面。当前初模属于轮廓加厚，侧面偏薄。如果目标是可以游泳、转身的小动物，应把腹部和背部做得更饱满，逐渐过渡到尾柄。不要直接对全部网格统一拉厚来代替侧面设计。
3. **精修表面**：以圆角立方体或曲线搭建新的主体，添加低等级细分；用边环控制蓝色外沿和腹部过渡。保留顶部水花的标志性形状。当前导出是三角网格，适合参考和直接显示；需要连续身体形变时应重新拓扑，避免直接对三角初模堆叠细分。
4. **处理接缝**：身体与尾巴现在是可独立运动的相交网格。最终模型需要重做尾柄连接，保证摆尾时不露缝。顶部蓝色形状本身就是喷出的水，单独建模并从头顶喷口生长，不能当成身体的固定附肢。
5. **建立材质**：身体采用低金属度的亮蓝陶瓷/软胶，水花采用更浅的青蓝色，眼睛采用黑色亮面。优先用真实灯光产生高光，避免把原图中的高光直接贴到所有视角。需在网页同样的环境光下检查颜色。
6. **加入动画结构**：第一轮可用身体、尾柄、尾尖、眼睛等少量关节或对象层级。`Idle` 做慢浮动，`Swim` 做尾巴延迟摆动，`Turn` 做倾斜转身，`Happy` 做轻弹跳，`Sleep` 做闭眼与呼吸。身体明显弯曲时再使用骨骼与权重。当前初模包含对象级 `Swim`，以及水花形变和水滴轨迹组成的 `Fountain`。
7. **导出网页版本**：应用必要的变换，清理隐藏测试件，导出 GLB 并带上命名动画。先以约 1–2 万三角形作为网页版本的预算起点，检查实际手机表现后再调整；不需要为一个小图标制作超高精度纹理。

## 喷水与网页接入

顶部原有水花是鲸鱼的识别特征，也代表喷泉中的水。根据用户确认，显示规则是：

1. **待机**：保留原来的完整顶部水花、轮廓和材质，不自动播放喷水。
2. **点击喷水**：水花先收至头顶喷口，从无到有地长出，轻微流动，水滴从两侧末端脱离。
3. **结束**：水滴消失，顶部恢复原来的完整造型并保留，不收空，也不自动循环。

当前使用原水花网格的形变目标，保留原始造型。水滴从两侧末端表面先聚起、拉出短水丝，连接处变细后断开；主水滴由拉长逐渐回圆，伴随细小飞溅。不同大小的水滴采用不同速度、重力与空气阻力近似，向前后散开再加速下落，避免整齐成串。水滴使用独立的透光材质及接近水的折射率（1.333）；原水花材质不变。每次喷水持续约 3.6 秒，轨迹可重复。

水花和水滴都在 `Fountain_Water` 分组内，跟随鲸鱼的移动、倾斜和厚度变化。喷水动画随 GLB 导出为 `Fountain`，包含形变与水滴位置、缩放、旋转；点击时身体轻微上浮由预览控制。这是轻量液滴动画，未使用完整流体模拟或物体碰撞求解。接入其他查看器时，需支持 glTF 的 transmission、volume 和 ior 材质扩展，才能还原水滴的透光效果。

播放 `Fountain` 时应使用单次播放并保持最后一帧；模型待机时和动画结束后，水花的形变权重均为零，表示原始完整造型。触发后的动画第一帧权重为一，把水花收至喷口，随后逐渐恢复。减少动态效果或切走页面时，预览停止喷水并恢复完整水花。

主页由 `WhalePet` 行为逻辑决定目标位置和状态，Three.js 显示模型和播放动作。使用透明背景，限制活动区域，滚动和选择文字时回到侧边；保留关闭、减少动态效果和 WebGL 不可用时的二维回退。相机、柔光环境、画布尺寸和页面运动速度一起决定最终观感。

“自由探索”保留为可选模式，目前在主页关闭。启用后点击追逐气泡，7.2 秒后回到侧边休息，也可按 Esc 中止。全页移动不写进 GLB，由网页计算视口内的路线；待机时不自动穿过正文。

## 已知边界

- 初模用于确定视觉方向。倒角使正面轮廓比二维参考略粗，侧面与背面仍需艺术设计。
- 中空版眼球是独立悬浮球体，这是标志的抽象表达；完整角色可选择腹部版。
- 当前尾巴属于刚体摆动，未实现柔性尾柄、眨眼形变、骨骼蒙皮或真实液体。
- 本地灯光/环境用于预览，不随 GLB 导出；接入网页后需设置等效照明。
- 本机未检测到 Blender，因此已验证 GLB 的重新加载与动画，尚未在 Blender 中实际导入检查。

## 第三方依赖

使用 Three.js **0.185.0** 的官方模块。模块与 MIT 许可证保存在 `scripts/whale-pet/3d/vendor/`，来源为 `https://cdn.jsdelivr.net/npm/three@0.185.0/`。`sync-homepage.mjs` 将主页所需模块、许可证及已验证模型复制到 `public/`，仅重写模块的本地导入路径，不依赖在线 CDN。模型几何来自本项目已有鲸鱼轮廓，没有复制参考网站的猫狗模型或行为代码。
