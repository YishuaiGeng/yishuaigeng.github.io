# Whale Pet · 动画与接入方案

2026-10-04：已在主页实现分层 SVG + CSS + 浏览器 Web Animations API 版本。包含轻浮动、眨眼、尾巴小幅摆动、喷水伸缩与水滴、点击开心、30 秒闲置睡眠。立体材质与轮廓来自 V0.2，没有增加动画库依赖。

入口为 `src/components/WhalePet.astro`，绘图为 `WhalePetArtwork.astro`，交互逻辑为 `src/scripts/whale-pet.ts`，设置与文案来自 `site.pet`。现已在所有屏幕宽度采用视口悬浮；宽度至少 1280 px 时停在左侧留白的中下部，窄屏停在左下方。下方保留原始规划，尚未实现的思考/阅读联动与复杂形变可继续扩展。

## 第一阶段：六状态切换与整体动作

| 场景                     | 素材       | 建议行为                                                   |
| ------------------------ | ---------- | ---------------------------------------------------------- |
| 日常待机                 | `idle`     | 4 秒一个周期，上下浮动约 4 px                              |
| 偶尔眨眼                 | `blink`    | 随机间隔 3–6 秒，闭眼约 160 ms 后回到当前基础状态          |
| 点击或键盘激活           | `happy`    | 轻微弹跳和喷水，约 1300 ms 后恢复                          |
| 用户停止操作             | `sleep`    | 约 30 秒后入睡，重新交互时唤醒                             |
| 明确的思考演示或真实等待 | `thinking` | 与真实事件关联，结束后恢复；装饰宠物不应伪装成系统加载指示 |
| 阅读文章或论文           | `reading`  | 后续可按页面或文章可见区域触发                             |

目前已实现待机、眨眼、点击开心和睡眠。当前点击会取消正在进行的眨眼与上次喷发；睡眠会停止喷水与尾巴摆动。阅读和思考保留为后续扩展。

按用户反馈已缩小 25%：桌面图片盒子为 132 px，手机为 108 px。宽屏固定在左侧留白，窄屏也保持悬浮；已避开右侧返回顶部按钮和固定页脚。自由游动及阅读伴游目前是设计提案，尚未接入主页。

## Astro 接入位置

- `src/config/site.ts` 提供带 JSDoc 的 `pet.enabled`、资源路径、尺寸、动作时长和 `labels`。按钮文字、辅助说明与其他可见文案都从配置传入。
- `src/components/WhalePet.astro` 由 `src/pages/index.astro` 引入，使第一版只出现在主页。需要全站显示时再移入 `src/layouts/Base.astro`。
- `WhalePetArtwork.astro` 将本地几何数据渲染为 SVG，并载入 `public/assets/img/whale-pet/layers/` 中的原图材质。通过图层显示切换表情，不重复载入六张整图。
- 暗色背景采用项目的 CSS 变量与 `[data-theme='dark']`。保留批准的蓝色材质，检查黑色眼睛和阴影的可读性，必要时使用柔和的背景衬底。
- 原生自定义元素的 `connectedCallback` 初始化、`disconnectedCallback` 清理定时器和事件；页面隐藏或宠物离开视口时暂停动画和计时器。
- 提供键盘激活、清晰焦点、关闭/隐藏入口；装饰图片避免重复读屏。尊重 `prefers-reduced-motion`，关闭浮动、弹跳和自动眨眼，保留静态交互反馈。

第一版验收：浅色/暗色、宽屏侧边不遮挡正文；窄屏悬浮仍可能覆盖局部正文，提供收起入口；键盘与关闭功能可用；切换路由不产生重复定时器；开启减少动态效果时保持静态。运行 `yarn check`、`yarn lint:ci`、`yarn build`，并检查实际浏览器表现。

## 第二阶段：尾巴与喷水单独运动

WebP / PNG 只能整体平移、缩放、旋转和切换状态，无法在 `<img>` 内单独摆动尾巴或喷水。需要这种效果时，改用可信的本地分层 SVG，或进一步制作动画素材。

已有 SVG 提供 body / tail / spout / eye 图层，可从这些转轴开始调整（1254 × 1254 内部坐标）：

| 图层  | 起始转轴建议 | 动作建议                           |
| ----- | ------------ | ---------------------------------- |
| tail  | `(919, 812)` | 小角度摆动，逐帧观察尾根接缝       |
| spout | `(577, 400)` | 轻微伸缩或摆动，检查材质裁切和阴影 |
| eye   | `(410, 690)` | 使用现有开闭眼状态或局部形变       |

当前已用上述尾巴与喷水转轴实现小幅运动，尚未创建骨骼绑定。绘图组件通过 `prefix` 为内部 ID 与滤镜/裁剪引用添加前缀；页面目前只有一个实例。始终以 PNG 外观作为对照，避免动画破坏当前立体感。

只有需要连续形变、复杂状态机、丰富拖拽反馈时，再评估 Rive 等工具；它不是第一版的必要依赖。
