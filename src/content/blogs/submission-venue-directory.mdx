## 等级与分区说明

CCF 等级按目录版本和研究方向确定。所附 2026 年版 PDF 将 ICLR 列为 A 类、IJCAI 列为 B 类（p.57–58）；其他年度目录或学校认定标准可能不同。

部分期刊属于多个方向：DKE 同属人工智能 B 类和数据库/数据挖掘/内容检索 B 类；IJIS 同属这两个方向的 C 类；IPL 同属计算机科学理论 C 类和数据库/数据挖掘/内容检索 C 类。

| 评价体系       | 等级或分区  | 适用信息                       |
| -------------- | ----------- | ------------------------------ |
| CCF 推荐目录   | A/B/C       | 目录版本、研究方向、期刊或会议 |
| 中科院期刊分区 | 1/2/3/4 区  | 分区年份、大类/小类、学科      |
| 新锐期刊分区   | 1/2/3/4 区  | 分区年份、学科及对应评价口径   |
| JCR            | Q1/Q2/Q3/Q4 | 年份与学科类别                 |

CCF 等级与期刊分区是独立的评价标签；JCR Q1 不直接等同于中科院或新锐 1 区。期刊分区不适用于会议。“未标注分区”表示本表没有对应分区数据，不代表该期刊未被 SCI/SCIE 收录。
