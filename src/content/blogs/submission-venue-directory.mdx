## 标签与关联规则

每个期刊或会议只维护一份基础资料，允许关联多个方向，并将不同评价体系分别记录。

| 标签维度   | 记录方式                                     | 使用规则                                           |
| ---------- | -------------------------------------------- | -------------------------------------------------- |
| 类型       | 期刊、会议                                   | 同名或同简称的期刊与会议分开建档                   |
| 方向       | 上述四个模块，可多选                         | 保留原目录所属方向，不用研究兴趣替代官方分类       |
| CCF        | 等级 + 目录年份 + 方向 + 来源页              | 如 `CCF B · 2026`；不同版本不混用                  |
| 中科院分区 | 体系 + 年份 + 大类/小类 + 学科 + 分区 + 来源 | 分区补录后与 CCF 标签并列                          |
| 新锐分区   | 体系 + 年份 + 学科/口径 + 分区 + 来源        | 按实际采用的分区文件记录，与历史中科院分区分开保存 |
| JCR        | 年份 + 学科 + Q1/Q2/Q3/Q4 + 来源             | JCR Q1 不直接等同于中科院/新锐 1 区                |
| 核验信息   | 来源链接、核验日期；期刊可补充 ISSN/eISSN    | 核对改名、同名期刊和年度变动                       |

**实际的跨方向关联：** DKE 同时属于人工智能 B 类和数据库/数据挖掘/内容检索 B 类；IJIS 同时属于这两个方向的 C 类；IPL 同时属于计算机科学理论 C 类和数据库/数据挖掘/内容检索 C 类。它们在各方向下展示，但共用一份期刊资料，后续分区只需补录一次。

例如某期刊核实为某年度“新锐 1 区”后，可同时带有 `CCF B · 2026` 与 `新锐分区 年份 1区` 标签。这里仅说明关联方式，**不据此给任何期刊预判分区**。会议不赋予期刊分区。

## 原文疑点与维护记录

- **WWW 期刊（p.68）**：B 类期刊表中的全称写为 “The Web Conference”，但给出的是 WWW 期刊链接。暂保留原文，并标注疑点；与 p.70 的 A 类 WWW 会议独立记录。
- **Pattern Recognition（p.53）**：期刊条目的网址指向 `/db/conf/par/`，疑似链接错误，暂不作为外链使用。
- **SIGSPATIAL（p.72）**：列在 C 类会议表中，但全称和网址与期刊/通讯条目相似，暂保留原文分类并标记待核实。
- **JATS（p.56）**：原文没有提供网址，保留空缺。
- 已清理 PDF 换行造成的简称拆分、网址空格与旧称括号；出版方按原文保存，未将其当作当前投稿入口。

## 后续补充分区与投稿信息

下一阶段优先补充与研究主题相关的 **1 区、2 区期刊**，并在每次补录时注明采用的是中科院分区、新锐分区还是 JCR，以及对应年份和学科。新锐分区与历史中科院分区的使用口径，以实际提供的文件及学校认定要求为准。

1. 先用完整刊名、ISSN/eISSN 和出版方确认期刊身份，再补入同一条记录；改名期刊保留旧称。
2. 保存分区来源、版本、学科、大类/小类等口径及核验日期。不同学科、不同年份的结果分别记录，不只保留最高分区。
3. 对已经在 CCF 目录中的期刊追加分区标签；CCF 之外的相关期刊，后续在扩展目录中新增独立记录。
4. 正式决定投稿前，再查看期刊/会议当年的研究范围、文章类型、截稿时间、版面费/OA 政策及投稿须知，并记录官网和查询日期。
